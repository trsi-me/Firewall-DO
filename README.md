# Firewall - DO

صفحة عربية تعرض اتصالات الجهاز عبر `netstat` وتحدّث الجدول كل 3 ثوانٍ. اسم المجلد يبدأ بعلامتي اتجاه من اليمين إلى اليسار (U+200F) ثم النص `Firewall - DO`. عنوان الصفحة داخل `index.html` هو Wireshark، والتذييل ينسب العمل إلى دانة العتيبي والسنة 2025.

بجانب الكود يوجد تسجيل `2025-03-12 22-03-23.mp4` بحجم يقارب 21377 كيلوبايت، وملف `Presentation.pptx`. محتوى الفيديو والعرض غير منسوخ هنا.

## 1. ما هو المشروع

`server.js` يشغّل Express وSocket.IO وينفّذ `netstat -an` ثم يبث الأسطر. `script.js` يرسم جدولاً: البروتوكول، العنوان المحلي، العنوان البعيد، الحالة. الزر الأول «راقب الشبكة» والثاني «وقف المراقبة».

فرض قواعد جدار حماية على النظام: «غير موجود في الملفات الحالية». العرض قراءة لمخرجات `netstat`.

## 2. لماذا يوجد هذا المشروع

الصفحة تسمّي الحركة «حركة الشبكة» وتطلب مراقبة. الخادم يعدّ العناوين التي ليست `0.0.0.0` وليست `127.0.0.1`. إذا تجاوز العدّاد `MAX_REQUESTS` وقيمته 30 تُطبع رسالة في الطرفية: تم اكتشاف عنوان شبكة مشبوه. المصفوفة `flaggedIps` تُبنى ولا تُرسل إلى المتصفح.

## 3. من يستخدمه

زائر الصفحة على الجهاز الذي يشغّل Node. حسابات: «غير موجود في الملفات الحالية».

## 4. ماذا يستطيع النظام أن يفعل

- تقديم `index.html` و`style.css` و`script.js` وخطوط Tajawal.
- بث `networkData` كل 3 ثوانٍ بعد اتصال المقبس.
- إظهار الجدول عند المراقبة وإخفاء زر البدء.
- قطع المقبس من المتصفح عند الإيقاف.
- طباعة العنوان الذي تجاوز 30 تكراراً في طرفية الخادم.

`package.json`: «غير موجود في الملفات الحالية». لا `package-lock.json`.

## 5. كيف يعمل النظام

```
المتصفح
  -> GET /
  -> زر راقب الشبكة
  -> Socket.IO
  -> كل 3000 مللي ثانية: netstat -an
  -> networkData
  -> صفوف الجدول
```

## 6. أمثلة واقعية

1. تثبيت express وsocket.io يدوياً لأن بيان الحزم غير موجود، ثم `node server.js`.
2. فتح `http://127.0.0.1:3000`.
3. الضغط على «راقب الشبكة» يملأ الجدول بحقول سطر `netstat`.
4. بعد تكرار عنوان أكثر من 30 مرة في دورات العدّ تُطبع رسالة الخادم.
5. «وقف المراقبة» يقطع مقبس هذا المتصفح.

## 7. رحلة المستخدم

فتح الصفحة، قراءة العنوان Wireshark، بدء المراقبة، مشاهدة الجدول، الإيقاف. لا حفظ ولا دخول.
